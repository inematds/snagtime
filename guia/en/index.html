What it is

Snag a time. Get booked.

A free and self-hostable scheduling app (MIT license). Instead of subscribing to a booking SaaS, you run your own—and customize whatever you want.

🆓 Local demo with no credentials

Free mode with SQLite, a local calendar, a local email inbox, and stub payments. It doesn't call Google or Stripe.

🔗 Real booking

Event types with multiple durations, weekly availability, date-specific exceptions, buffers, minimum notice, a scheduling window, and public links with time zone support.

🔒 Hardened production

PostgreSQL 18 architecture with forced row-level security, separate app and worker credentials, verified TLS to the database, and authenticated ingress.

How it works

From setup to confirmed scheduling

The flow from organizer to guest—all within your installation.

npm run setup→ Workspace→ Event type→ Availability→ Public link→ Guest schedules→ Email confirmation→ Reschedule / cancel

👥 Workspaces

Sign-up, login, password recovery, email verification, members, invitations, and workspace switching.

🗓️ Schedule

Google Calendar free/busy check and event creation on the organizer's calendar.

🎨 Branding

Workspace branding: accent color, profile image, and uploaded logo.

User guide · step by step

SnagTime up and running in five minutes

Actual repository commands. By the end, you'll have the app running at localhost:3000 with an organizer login already created.

1

Clone the repository

Download the code and enter the folder.

git clone https://github.com/inematds/snagtime.git
cd snagtime
2

Generate the local configuration

Creates a .env.local ignored by git, generates independent cryptographic secrets, and prints the demo login once.

npm run setup

# or with your own organizer login:
npm run setup -- --email voce@exemplo.com --password "SuaSenhaForte7!"
3

Install, migrate, and deploy

One command: installs, runs migrations, seeds the database, and starts the free demo.

npm run demo:free  # open http://localhost:3000
4

Check the configuration

Validates the local setup without credentials if something doesn’t start as expected.

npm run setup:check
5

Day-to-day commands

Development, tests, and production build.

npm run dev              # development server
npm run test             # unit and contract tests
npm run typecheck        # TypeScript
npm run lint             # ESLint
npm run build            # Next.js production build
npm run ci:secret-scan   # scans public code for credentials
6

Database

db:reset destroys the local SQLite database—use only when you want a clean demo.

npm run db:generate
npm run db:migrate
npm run db:seed
npm run db:reset        # destructive
7

Install with AI assistance

The repository includes a ready-to-use prompt for Codex or Claude Code to guide the installation, stopping only at account setup steps that only you can complete.

# docs/AI-SETUP.md — copy the student's prompt and paste it into the assistant with:
https://github.com/inematds/snagtime
