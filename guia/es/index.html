Agendamiento autohospedado · MIT

Tu propio sistema de agendamiento, ejecutándose en tu máquina.

SnagTime es el código fuente de una app completa de agendamiento: disponibilidad, enlaces públicos de booking, Google Calendar, correos y pagos en modo de prueba. Se ejecuta localmente en cinco minutos, sin credenciales.

Comenzar la guía Ver en GitHub
Qué es

Snag a time. Get booked.

Una app de agendamiento libre (licencia MIT) y autoalojable. En lugar de suscribirte a un SaaS de reservas, ejecutas el tuyo y lo personalizas como quieras.

🆓 Demo local sin credenciales

Modo gratuito con SQLite, calendario local, bandeja de correo local y pagos stub. No llama a Google ni a Stripe.

🔗 Booking real

Tipos de evento con varias duraciones, disponibilidad semanal, excepciones por fecha, márgenes, anticipación mínima, ventana de agendamiento y enlaces públicos con zona horaria.

🔒 Producción reforzada

Arquitectura PostgreSQL 18 con row-level security forzada, credenciales de app y worker separadas, TLS verificado en la base de datos e ingress autenticado.

Cómo funciona

Desde la configuración hasta el agendamiento confirmado

El flujo del organizador hasta el invitado, todo dentro de tu instalación.

npm run setup→ Workspace→ Tipo de evento→ Disponibilidad→ Enlace público→ El invitado agenda→ Confirmación por correo electrónico→ Reprogramar / cancelar

👥 Workspaces

Registro, inicio de sesión, recuperación de contraseña, verificación de correo electrónico, miembros, invitaciones y cambio de workspace.

🗓️ Agenda

Verificación de disponibilidad free/busy en Google Calendar y creación del evento en el calendario del organizador.

🎨 Marca

Branding del workspace: color de énfasis, imagen de perfil y logo subido.

Guía de uso · paso a paso

SnagTime funcionando en cinco minutos

Comandos reales del repositorio. Al final tienes la app en localhost:3000 con el inicio de sesión del organizador ya creado.

1

Clonar el repositorio

Descarga el código y entra en la carpeta.

git clone https://github.com/inematds/snagtime.git
cd snagtime
2

Generar la configuración local

Crea un .env.local ignorado por git, genera secretos criptográficos independientes e imprime los datos de acceso a la demo una sola vez.

npm run setup

# o con tu propio inicio de sesión de organizador:
npm run setup -- --email voce@exemplo.com --password "SuaSenhaForte7!"
3

Instalar, migrar y desplegar

Un solo comando: instala, aplica las migraciones, carga la base de datos e inicia la demo gratuita.

npm run demo:free  # abre http://localhost:3000
4

Verificar la configuración

Valida la configuración local sin credenciales, por si algo no inicia como esperabas.

npm run setup:check
5

Comandos del día a día

Desarrollo, pruebas y build de producción.

npm run dev              # servidor de desarrollo
npm run test             # pruebas unitarias y de contrato
npm run typecheck        # TypeScript
npm run lint             # ESLint
npm run build            # build de producción de Next.js
npm run ci:secret-scan   # busca credenciales en el código público
6

Base de datos

db:reset destruye el SQLite local; úsalo solo cuando quieras una demo limpia.

npm run db:generate
npm run db:migrate
npm run db:seed
npm run db:reset        # destructivo
7

Instalar con ayuda de IA

El repositorio incluye un prompt listo para que Codex o Claude Code guíen la instalación, deteniéndose solo en los pasos de cuenta que solo tú puedes realizar.

# docs/AI-SETUP.md — copia el prompt del estudiante y pégalo en el asistente con:
https://github.com/inematds/snagtime
